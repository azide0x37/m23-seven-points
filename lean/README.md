# m23-lean — formal certification of the M23 seven-cover census

Lean 4 (v4.15.0), **mathlib-free**. Certifies the finite combinatorial core
of the M23 Nielsen-class analysis (HJLPPZ arXiv:2608.08538 context):

> Let G = ⟨g1,g2⟩ ≤ Sym(23) (paper generators; |G| = 10,200,960).
> The set of pairs (x,y) with x ∈ cls(g1) [2A], y ∈ cls(g2) [23A],
> (xy)⁻¹ ∈ cls(g3) [23B], ⟨x,y⟩ = G has exactly SEVEN orbits under
> simultaneous conjugation (paper labels 1–7), and the involution
> κ: (x,y) ↦ (x, xy) (= complex conjugation's combinatorial shadow,
> given the branch-cycle formula) permutes them by (1 2)(5 7),
> fixing labels 3, 4, 6.

The analytic bridge ("complex conjugation acts by the Dèbes–Fried
branch-cycle formula") is NOT formalized — it is the one explicitly
quarantined hypothesis. Everything after it is certified here.

## Architecture / trust model

| file        | content                                          | trust |
|-------------|--------------------------------------------------|-------|
| Defs.lean   | perms as `List Nat`, mul/inv/conj, words         | defs  |
| Sims.lean   | verified BSGS-certificate checker (`checkChain`) | defs  |
| Data.lean   | AUTO-GENERATED certificates (715 KB)             | data  |
| Kernel.lean | products, orders, |G| via chain, class certs, σ-certs, 7 pair-chains | `decide` (kernel only) |
| Native.lean | ONE enumeration: classes (443,520), Y (18,816), 7 regular C-orbits partition Y | `native_decide` (compiler-trusting, quarantined) |
| Census.lean | final statements + glue roadmap G1–G5            | `sorry` pending glue |

Certificate design (validated numerically, `lean-census-derisk-receipt.json`):
anchoring x ↦ g1 reduces the census to orbits of C = C_G(g1) (order 2,688,
generated by 2 elements) on Y (18,816 = 7×2,688); all orbits regular
(Z(G)=1); κ on the anchored slice is literally y ↦ g1·y; generation
vacuity follows from coverage + 7 order-equality chain certificates —
no 18,816-fold generation check needed.

## Build

```

cd outputs/m23-lean && lake build
```
Expected: Kernel/Native theorems all check; Census.lean warns on `sorry`
(glue G1–G5 = the remaining ~1–2 month formalization work; statements are
final). Mnemosyne job `job008-lean-build-derisk.py` runs this build
unattended in-container and reports per-step timings — the kernel-`decide`
budget derisk. If a Kernel theorem exceeds kernel budget, flip that one
proof to `native_decide` (per-fact TCB tradeoff, keep the flip documented).

sandbox-report.json + the paper generators. The in-container copy in
job008 is normalized-identical (verified).

## Glue roadmap (G1–G5, see Census.lean header)

G1 checkChain soundness → |⟨gens⟩| = chainOrder (orbit–stabilizer
induction). G2 anchoring bijection. G3 bigCheck soundness (List-BFS
reflection). G4 generation transport. G5 κ well-definedness. G1 and G3
are the substantive ones; both are self-contained inductions over the
checker definitions, no external mathematics.
